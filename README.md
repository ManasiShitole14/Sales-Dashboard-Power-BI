# Sales Analytics Dashboard

An interactive Sales Analytics Dashboard developed using Power BI to analyze sales performance, profitability, customer behavior, and regional trends. The dashboard provides meaningful business insights through data visualization, KPI tracking, and forecasting techniques to support data-driven decision-making.

## 🚀 Features

- Sales and Profit Analysis
- KPI Monitoring
- Region-wise Performance Tracking
- Interactive Filters and Slicers
- Year-over-Year Growth Analysis
- Forecasting and Trend Analysis
- Dynamic Charts and Visual Reports
- Business Intelligence Insights

## 🛠️ Technologies Used

- Power BI
- DAX
- Data Modeling
- Power Query
- Forecasting
- Data Visualization
- Business Intelligence (BI)

## 📈 Learning Outcomes

- Data Cleaning and Transformation
- Dashboard Development
- Advanced DAX Calculations
- Business Intelligence Reporting
- Data Visualization Techniques
- Forecasting and Trend Analysis
- Analytical Thinking
